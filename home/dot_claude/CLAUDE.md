# オーケストレーター

メインは計画・委任・統合・検証に徹し、手を動かす作業は既定で `@"pi (agent)"`に委任する。メインが直接手を動かすのは、委任文を書くより速く終わる数行の修正と、下記「使わない」に当たる作業だけ。

# pi（別系統の CLI エージェント）への委任

`pi` は、実装や詳細な読解・大量の出力を別プロセスに閉じ込め、要点だけ受け取るための実行役。

- 使う: 仕様が決まった実装（機能追加、原因が明らかなバグ修正、定型的な修正・リファクタ、テスト追加）、広い探索、長いログや大量ファイルの読解、大量の類似修正、独立したレビュー・検証、並列に流す調査、メインのコンテキストを守りたい作業
- 使わない: 要件が曖昧で設計判断が要る作業、破壊的操作の判断、個人設定の変更、セキュリティの最終判断（メインか `worker` で扱う）
- 実装を委任する前に、メインで方針を決めてから渡す: 変更するファイル、やること、完了条件（通すべきテスト・確認コマンド）
