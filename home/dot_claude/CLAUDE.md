# サブエージェント
委任は `worker`（既定 Sonnet/medium）を使い、メインは計画・統合・レビューに専念する。起動ごとにタスクを判定し、既定以外は Agent の `model`/`effort` で上書きする（effort 指定を許可）。
- Haiku/medium: 検索、要約・抽出、分類、テスト実行と報告など範囲が狭く結果を確かめやすい作業。コード修正の判断とセキュリティ関連には使わない
- Sonnet/medium（既定）: コード調査、定型的な修正、原因が明らかなバグ修正、ドキュメント
- Sonnet/high: 複数ファイルの実装、原因不明のデバッグ、テスト設計、リファクタリング、コードレビュー
- Opus/medium: 曖昧な要件、設計比較、モジュール横断の調査、成果物の検証、セキュリティレビュー
- Opus/high: 下位の設定で失敗した難しいバグ、取り消しにくい変更の計画（例外的に使う）
迷ったら Sonnet/medium。結果が不十分なら一段上げて再試行する。
