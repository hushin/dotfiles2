# DSH Edit Last Message

DeepSeek Harness の Web GUI で「直近に送信したユーザーメッセージ」を編集するための
ローカルバンドルです。同じセッションのまま、送信済みメッセージをモデルの文脈から
取り下げて入力欄に戻します。fork やセッション切り替えはしません。

## 使い方

1. 直近に送信したメッセージのアクション列 (コピーボタンの左隣) の鉛筆アイコンを押す
2. **編集モード**に入る。会話はそのまま表示され、元の文が入力欄に戻る
3. 文を直して送信 (Enter または送信ボタン) すると、元のターンを取り下げてから
   修正後の文を送信する
4. やめるときは、入力欄の上に出るバーの「編集をキャンセル」を押す。会話も入力欄も
   元に戻り、何も取り下げられない

編集モード中の送信はプラグインが横取りし、必ず「取り下げ → 送信」の順で実行します
(同じ文が二重に送られることはありません)。`/` で始まるコマンド入力中は横取りせず、
通常どおりコマンドとして実行します。

入力欄に下書きがあるとき、添付が付いているとき、直近メッセージが添付付きのときは
編集モードに入れません (下書きや添付を失わないため)。

スラッシュコマンド `/edit-last` でも同じ操作ができます (`/edit-last @<seq>` で
対象を明示)。サブエージェントのセッションでは使えません。

## 仕組み

- Host (`index.js`): `edit-last` コマンドを登録。最新の人間の `user/message` を
  surface 上で検証し、`surfaceOp: { op: 'replace', startSeq, endSeq }` と
  `sourceEventSeqs` を持つ replacement `user/message` を追記します。セッションログは
  append-only のままなので、replay / resume / fork は追記後の surface から文脈を
  再構築します。置換ノードの source kind は `dsh-edit-last`、本文は
  `(message withdrawn for editing)` です。
- Client (`client.js`): 直近ユーザーメッセージのアクション列に鉛筆を差し込みます
  (Chat の行レンダラをラップして Copy と同じ flex 行に `order: -1` で追加)。
  クリックではまだログを触らず、入力欄に本文を入れて編集モードに入ります。送信時に
  Enter と送信ボタンを横取りし、コマンドで旧ターンを取り下げてから facade の
  `submit` で修正後の文を送ります。キャンセルは入力欄を元の下書きに戻すだけです。
  さらに Chat の view builder をラップし、適用済みの編集の `[target..marker]` 範囲と
  自プラグインの置換ノードを `visibility: 'hidden'` にします。Chat 側はこの visibility
  を並び順・ターン移動・グルーピング・仮想化に反映するので、置き換えたターンだけが
  画面から消え、それより上のログは表示されたまま残ります。

## 制約

- ログ自体は消えません。Trajectory やセッション検索、ロスレス書き出しには古い
  イベントが残ります。
- ツールの副作用 (ファイル変更・プロセス・バックグラウンドジョブ) は巻き戻しません。
  モデルの文脈と表示だけが対象です。
- 添付付きメッセージの編集は未対応です (入力欄に画像・ファイルを戻せないため)。
- 置換ノードはモデルにも 1 通の user メッセージとして見えます。直後に編集後の
  プロンプトが続くため、実質は「取り下げの目印 + 新しい依頼」です。
- Chat の view builder ラップは Harness の内部レジストリに依存します。Harness を
  更新したら、まずこのボタンと非表示動作を確認してください。

## インストール / アンインストール

`plugin_manager` の `install_bundle` にこのディレクトリの絶対パスを渡します。
アンインストールは `plugin_manager` の `remove_bundle` で `dsh-edit-last` を外します。
